## 📖 项目简介

**银发守护**是一款面向独居老人的**手环+桌面Hub双端AI守护系统**，解决"老人离开桌面终端即失联、突发状况家属无从知晓"的痛点问题。

### 核心亮点

- 🆘 **SOS一键呼救**：手环按键，秒级通知家属
- 🪑 **久坐/静止检测**：六轴IMU，智能识别异常状态
- 💊 **用药提醒**：Hub大字显示+语音播报，手环同步
- 🎤 **语音闲聊**：情感陪伴，健康数据语音记录
- 📱 **异常告警**：多级推送，确保家属知晓

---

## 🎯 问题背景

中国已进入深度老龄化社会，独居老人数量持续增长。现有智能穿戴设备存在明显痛点：

- **失联问题**：老人离开桌面终端后，家属无法知晓其状态
- **响应延迟**：突发状况时，无法第一时间通知家属
- **功能单一**：传统手环仅有健康监测，缺乏主动关怀
- **交互困难**：老人对复杂智能设备操作困难

**银发守护系统**采用**手环+桌面Hub双端协同架构**，实现全天候、全场景的老人守护。

## 🔧 硬件选型

### 手环端：黄山派SF32LB52

**选择理由**：
- ✅ 专为穿戴设备设计，低功耗优化
- ✅ BLE 5.0 支持，稳定连接
- ✅ 六轴 IMU 集成，运动检测精准
- ✅ LCD 驱动支持，界面友好
- ✅ openvela 系统支持，开发便捷

**核心参数**：
- 处理器：ARM Cortex-M4F @ 64MHz
- 无线：BLE 5.0
- 传感器：六轴 IMU（加速度+陀螺仪）
- 显示：LCD 屏幕（支持 LVGL）
- 功耗：超低功耗设计，续航7天+

---

### Hub端：润芯微Gemini-S1

**选择理由**：
- ✅ 音频能力完整（双麦克风+扬声器）
- ✅ WiFi 连接，云端通信稳定
- ✅ LCD 大屏显示，老人友好
- ✅ AI Agent 框架支持
- ✅ 计算能力充足

**核心参数**：
- 处理器：ARM Cortex-A7 @ 1.2GHz
- 无线：WiFi 802.11 b/g/n
- 音频：双麦克风阵列 + 扬声器
- 显示：LCD 大屏（支持大字体）

## 📋 核心功能

### 1. SOS 一键呼救 ⚠️

**场景**：老人突发状况（跌倒、心脏病发作等）

**流程**：
1. 老人长按手环 SOS 按键（3秒）
2. 手环震动确认，屏幕显示"SOS已发送"
3. BLE 通知 Hub 端
4. Hub 语音播报 + LCD 显示
5. WiFi 推送告警到家属手机
6. 家属收到短信/APP推送/电话通知

### 2. 久坐/长时间静止检测 🪑

**场景**：老人长时间不活动，可能存在健康风险

**流程**：
1. 手环六轴 IMU 持续采集运动数据
2. 端侧算法判定：久坐>60分钟/静止>2小时
3. 手环震动提醒，屏幕显示提示
4. Hub 语音播报提醒
5. 数据记录到云端，生成健康报告

### 3. 用药提醒 💊

**场景**：老人需要按时服药，避免遗忘

**流程**：
1. 家属通过 APP 设置用药计划
2. 到达提醒时间，Hub 触发提醒
3. LCD 大字显示用药信息
4. 扬声器语音播报
5. 手环屏幕同步显示，震动提醒
6. 老人确认后，记录服药时间

### 4. 语音闲聊与健康数据记录 🎤

**场景**：老人感到孤独，需要情感陪伴

**流程**：
1. 老人对 Hub 说"小银小银，陪我聊聊天"
2. Hub 麦克风采集语音，ASR 识别
3. 云端 LLM 生成回复
4. Hub 扬声器播报回复
5. 对话记录保存，家属可查看

### 5. 异常告警推送家属 📱

**场景**：检测到异常情况，需要通知家属

**告警等级**：
- 🔴 **紧急**：SOS、跌倒 → 电话+短信+APP
- 🟠 **重要**：心率异常、长时间静止 → 短信+APP
- 🟡 **一般**：久坐提醒、用药提醒 → APP

## 💻 技术方案

### 手环端技术栈

```
操作系统：openvela（基于 NuttX）
UI 框架：LVGL
传感器驱动：六轴 IMU（I2C/SPI）
无线协议：BLE 5.0 GATT
开发语言：C
构建系统：CMake + Make
```

### Hub端技术栈

```
操作系统：openvela（基于 NuttX）
AI 框架：AI Agent 框架
音频处理：ASR/TTS 库
网络：WiFi + HTTP/MQTT
UI：LCD 驱动 + 自定义 UI
开发语言：C/C++ + Python（AI）
```

### 云端技术栈

```
AI 模型：LLM（对话、ASR、TTS）
后端：Python + FastAPI
数据库：PostgreSQL + Redis
消息队列：RabbitMQ
推送服务：极光推送 / 个推
```

## 🚀 运行方式

### 环境准备

```bash
# 1. 安装 WSL2 Ubuntu 24.04
wsl --install -d Ubuntu-24.04

# 2. 拉取 openvela 工程
repo init -u https://github.com/open-vela/contest2026_325_junweiyanjiuyuan \
  -b dev-ai-contest-2026 -m contest2026_325_junweiyanjiuyuan.xml
repo sync -c -j8

# 3. 进入工作区
cd ~/contest2026_325_junweiyanjiuyuan
```

### 手环端编译

```bash
# 进入 openvela 工作区根目录
cd ..

# 编译（需要 SF32LB52 开发板）
./build.sh vendor/sifli/boards/sf32lb52/lckfb_huangshan_pi/configs/nsh -j8

# 烧录
# 使用 J-Link 或串口烧录到 SF32LB52 开发板
```

### Hub端编译（Gemini-S1，已验证 ✅）

```bash
# 进入 openvela 工作区根目录
cd ..

# 编译（2.8寸 SPI 屏配置，已实测通过）
./build.sh vendor/allwinnertech/boards/r528/r528s3-gemini-s1/configs/nsh_minidisplay/ -j8

# 打包固件（在 lichee 目录）
cd vendor/allwinnertech/lichee
source envsetup.sh
lunch_nuttx r528s3-gemini-s1
pack

# 烧录
# 用 PhoenixSuit 烧录 out/r528s3/gemini-s1_nand/rtos_nuttx_r528s3-gemini-s1_uart0_128Mnand.img
# 注意：烧录需使用出厂固件配套的 fes1/boot0（详见 docs/开发文档）
```

### 运行测试
