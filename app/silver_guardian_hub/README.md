# Silver Guardian Hub - Hub端应用

运行在润芯微 **Gemini-S1**（全志 R528-S3 + 2.8寸触摸屏）上的 openvela 应用。

> **状态（2026-09-13）：已上板可交互，全部功能真机验证通过。**
> 构建标记 `SGHUB-BUILD-20260913-LINK`，版本 1.9.0。

---

## 核心功能

### 1. 事件系统（一切提示的统一入口）
所有告警——不管是本机触发还是手环端发来的——都走同一条通路：

```
事件产生（本机按键 / 板间联动 / 用药到点）
        ↓
   事件队列（优先级 + 环形历史 32 条）
        ↓
   事件处理器
        ↓
├─ 提示音        audio.c
├─ 屏幕警示层    lcd.c   （大字中文 + 分级配色）
├─ 分色指示灯    led.c   （WS2812 RGB）
└─ 事件记录页    ui.c    （最近发生过什么）
```

### 2. 多页触摸界面（LVGL 9）
主页（时钟/日期/守护状态）、功能菜单、用药提醒、用药编辑、健康数据（板上传感器）、
事件记录、设置、**日期时间校准**、**网络设置**、关于/自检、触摸自检。

### 3. 分色指示灯
板载 **WS2812B**（走 LEDC 控制器，设备节点 `/dev/leds0`）：

| 事件 | 颜色 | 节奏 |
|---|---|---|
| SOS / 跌倒 | 🔴 红 | 快闪 4Hz（保持 5 分钟） |
| 久坐 | 🟡 黄 | 慢闪 1Hz（30 秒） |
| 用药提醒 | 🟢 绿 | 慢闪 1Hz（30 秒） |
| 点"知道了" / 恢复活动 | 熄灭 | — |

> ⚠️ 硬件手册写的 `SYS_LED = PB10` 在这块板子上**点不亮可见灯**（实测对比过），
> 真正可见的是这颗 WS2812。别照着手册去翻 GPIO。

### 4. WiFi 配置界面
设置 → 网络设置 → 扫描 → 选 AP → LVGL 全屏键盘输密码 → 连接。
联网后自动 SNTP 校时，状态栏如实显示"已联网"/"离线"。

### 5. 用药提醒
屏幕直接添加计划（时间/药名/剂量），存 `/data` 断电不丢；到点大字显示 + 语音 + 绿灯。

### 6. 板间联动（接收端）
UDP 5555 监听手环端报文，`SG1 ` 前缀文本协议，翻译成事件走上面那条统一通路。
**协议详见 [`docs/开发文档/17_板间联动协议.md`](../../docs/开发文档/17_板间联动协议.md)。**

### 7. 自检报告
每 30 秒把各模块真实状态写到 `/data/silver_guardian/diag.txt`，
接 adb 就能看"哪个设备节点没打开、errno 多少、传感器读到没有"：

```bash
adb shell "cat /data/silver_guardian/diag.txt"
```

## 编译与烧录

**不要手动跑 build.sh + pack**，用固化的脚本（内含多个无法绕过的步骤）：

```bash
bash tools/build_hub.sh     # 编译（含源码同步 + 强制重编 + 构建标记校验）
bash tools/pack_hub.sh      # 打包成可烧 .img（固化出厂 fes1/boot0）
```

烧录用 PhoenixSuit，模式选「全盘擦除升级」，**板子断电 3~5 秒再上电**。

详细流程与排障见 [`docs/开发文档/15_Hub端完整编译烧录实操手册.md`](../../docs/开发文档/15_Hub端完整编译烧录实操手册.md)。

## 目录结构

```
silver_guardian_hub/
├── src/
│   ├── main.c          主程序与主循环（10ms）
│   ├── event.c         事件系统

│   ├── lcd.c           显示层（状态栏/警示层/触摸）

│   ├── led.c           WS2812 分色指示灯

├── Makefile
└── README.md
```

## 几个容易踩的坑（都在源码注释里写明了）

| 坑 | 表现 | 处理 |
|---|---|---|
| **LTO 符号撞车** | 裸 `led_off()` 与厂商 `luncher_mini` 的符号 multiple definition | 对外符号一律加 `sg_` 前缀 |
| **头文件改动不生效** | 改了 `.h` 构建标记却不变 | 本 app 无 `src/Make.dep`，`build_hub.sh` 已加强制 touch |
| **事件系统非线程安全** | `event_send()` 操作全局队列无锁 | 收包线程只入队，主循环出队并产生事件 |
| **提示音被截断** | 送 8320 字节实际只进 4096 | 驱动单块 2048×2；出声后需多轮 enqueue |
