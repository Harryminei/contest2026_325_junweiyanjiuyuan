## 🚀 使用建议

### 新成员入门
1. 阅读 [开发文档/00_项目总览.md](开发文档/00_项目总览.md)（15分钟）
2. 阅读 [开发文档/02_硬件选型.md](开发文档/02_硬件选型.md)（20分钟）
3. 配置开发环境（参考 openvela开发操作手册/）
4. 阅读 [开发文档/10_开发操作手册.md](开发文档/10_开发操作手册.md)

### 手环端开发
1. 阅读 [开发文档/02_硬件选型.md](开发文档/02_硬件选型.md)
2. 阅读 [开发文档/01_技术方案.md](开发文档/01_技术方案.md)（手环端部分）
3. 阅读 [开发文档/10_开发操作手册.md](开发文档/10_开发操作手册.md)（手环端章节）

### Hub端开发
1. 阅读 [开发文档/02_硬件选型.md](开发文档/02_硬件选型.md)
2. 阅读 [开发文档/15_Hub端完整编译烧录实操手册.md](开发文档/15_Hub端完整编译烧录实操手册.md)（**编译烧录照这份做**）
3. 阅读 [开发文档/16_Hub单板功能实现与触摸中文字体修复.md](开发文档/16_Hub单板功能实现与触摸中文字体修复.md)（排障速查）

### 手环端接入 Hub（板间联动）
1. 阅读 [开发文档/17_板间联动协议.md](开发文档/17_板间联动协议.md) —— 端口、报文格式、实现要点都在里面
2. 用电脑先冒充手环发一条 `SG1 SOS` 验证 Hub 接收链路（文档里有现成的 PowerShell 命令）
3. 再做手环端的发送实现
