## 🚀 快速开始

**新手推荐路径**：
1. 阅读 `01_开发环境快速配置指南.md`（5分钟）
2. 按照 `02_系统配置完整流程.md` 逐步操作（30-60分钟）
3. 使用 `04_环境验证报告.md` 验证配置
4. 阅读 `06_开发环境使用手册.md` 开始开发

**有经验的开发者**：
1. 直接查看 `02_系统配置完整流程.md` 的核心步骤
2. 参考 `06_开发环境使用手册.md` 的开发流程
