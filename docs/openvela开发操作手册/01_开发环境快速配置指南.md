## 🎯 目标

## 📦 配置概览

### 你需要什么
- ✅ WSL2 + Ubuntu 24.04
- ✅ 核心开发工具（GCC、Git、Python 等）
- ✅ Repo 工程代码
- ✅ 开发编辑器（可选）

### 配置步骤（5步）

```
步骤 1️⃣  检查 WSL2 环境（2分钟）
    ↓
步骤 2️⃣  安装开发工具（10分钟，后台运行）
    ↓
步骤 3️⃣  配置环境变量（1分钟）
    ↓
步骤 4️⃣  拉取工程代码（15-30分钟，后台运行）
    ↓
步骤 5️⃣  验证配置（2分钟）
    ↓
✅ 完成！开始开发
```

---

## ⚡ 快速命令

### 检查 WSL2
```bash
# 在 Windows PowerShell/CMD 中
wsl -l -v
# 应该看到 Ubuntu-24.04 Running
```

### 进入开发环境
```bash
# 进入 WSL2
wsl -d Ubuntu-24.04

# 进入工作目录
cd ~/contest2026_325_junweiyanjiuyuan

# 加载环境变量
source ~/.bashrc
```

### 验证工具
```bash
# 快速验证
gcc --version | head -1
git --version
python3 --version
repo --version | head -3
```
