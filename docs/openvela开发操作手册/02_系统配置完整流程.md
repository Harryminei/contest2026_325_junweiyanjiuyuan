## 🚀 详细步骤

### 步骤 1：检查 WSL2 环境（2分钟）

#### 1.1 检查 WSL2 是否安装
```bash
# 在 Windows PowerShell/CMD 中执行
wsl -l -v
```

**预期输出**：
```
  NAME              STATE           VERSION
* Ubuntu-24.04      Running         2
```

#### 1.2 如果未安装 WSL2
```bash
# 以管理员身份运行 PowerShell
wsl --install -d Ubuntu-24.04

# 重启计算机
# 配置用户名和密码
```

#### 1.3 进入 WSL2
```bash
wsl -d Ubuntu-24.04
```

**验证**：
```bash
whoami
# 应该显示：harryminei

uname -a
# 应该显示：Linux ... x86_64 GNU/Linux
```

---

### 步骤 2：安装开发工具（10分钟）

#### 2.1 更新包管理器
```bash
sudo apt-get update
sudo apt-get upgrade -y
```

#### 2.2 安装核心工具
```bash
# 安装 GCC 和编译工具
sudo apt-get install -y \
  gcc \
  g++ \
  make \
  cmake \
  build-essential

# 安装 Git
sudo apt-get install -y git

# 安装 Python
sudo apt-get install -y \
  python3 \
  python3-pip \
  python3-venv

# 安装串口工具
sudo apt-get install -y minicom

# 安装其他工具
sudo apt-get install -y \
  vim \
  curl \
  wget \
  unzip
```

#### 2.3 安装 ARM 交叉编译工具链
```bash
# 下载 ARM GCC 工具链
wget https://developer.arm.com/-/media/Files/downloads/gnu/13.2.rel1/binrel/arm-gnu-toolchain-13.2.rel1-x86_64-arm-none-eabi.tar.xz

# 解压
tar -xf arm-gnu-toolchain-13.2.rel1-x86_64-arm-none-eabi.tar.xz

# 移动到 /opt
sudo mv arm-gnu-toolchain-13.2.rel1-x86_64-arm-none-eabi /opt/

# 添加到 PATH
echo 'export PATH="/opt/arm-gnu-toolchain-13.2.rel1-x86_64-arm-none-eabi/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

**验证安装**：
```bash
gcc --version
arm-none-eabi-gcc --version
git --version
python3 --version
make --version | head -1
cmake --version | head -1
minicom --version | head -1
```

---

### 步骤 3：配置环境变量（1分钟）

#### 3.1 编辑 ~/.bashrc
```bash
vim ~/.bashrc
```

#### 3.2 添加以下内容
```bash
# Repo 工具路径
export PATH="$HOME/.bin:$PATH"

# 语言设置
export LANG=en_US.UTF-8
export LC_ALL=en_US.UTF-8

# 开发工具路径（如果手动安装）
export PATH="/opt/arm-gnu-toolchain-13.2.rel1-x86_64-arm-none-eabi/bin:$PATH"
```

#### 3.3 使配置生效
```bash
source ~/.bashrc
```

**验证**：
```bash
echo $PATH | grep -q '.bin' && echo "✅ PATH 配置正确" || echo "❌ PATH 配置错误"
echo $LANG
# 应该显示：en_US.UTF-8
```

---

### 步骤 4：安装 Repo 工具（2分钟）

#### 4.1 创建目录
```bash
mkdir -p ~/.bin
```

#### 4.2 下载 repo
```bash
curl https://storage.googleapis.com/git-repo-downloads/repo > ~/.bin/repo
chmod a+x ~/.bin/repo
```

**如果无法访问 Google**：
```bash
# 使用清华镜像
curl https://mirrors.tuna.tsinghua.edu.cn/git/git-repo -o ~/.bin/repo
chmod a+x ~/.bin/repo
```

#### 4.3 验证安装
```bash
repo --version
# 应该显示：repo launcher version 2.xx
```

---

### 步骤 5：拉取工程代码（15-30分钟）

#### 5.1 创建工作目录
```bash
mkdir -p ~/contest2026_325_junweiyanjiuyuan
cd ~/contest2026_325_junweiyanjiuyuan
```

#### 5.2 初始化 Repo
```bash
repo init -u https://github.com/open-vela/contest2026_325_junweiyanjiuyuan \
  -b dev-ai-contest-2026 \
  -m contest2026_325_junweiyanjiuyuan.xml
```

**如果遇到网络问题**：
```bash
# 设置 Git 代理（如果有）
git config --global http.proxy http://proxy:port
git config --global https.proxy http://proxy:port

# 或使用国内镜像
export REPO_URL='https://gerrit-googlesource.lug.ustc.edu.cn/git-repo'
repo init -u https://github.com/open-vela/contest2026_325_junweiyanjiuyuan \
  -b dev-ai-contest-2026 \
  -m contest2026_325_junweiyanjiuyuan.xml
```

#### 5.3 同步代码
```bash
# 同步（-j4 表示4个并行任务）
repo sync -c -j4

# 如果网络不稳定，减少并行数
repo sync -c -j2
```

**这一步需要较长时间**，可以：
- 开新终端继续其他工作
- 使用 `tail -f` 查看日志
- 或者后台运行：`repo sync -c -j4 &`

#### 5.4 验证同步
```bash
ls -la
# 应该看到以下目录：
# app/
# apps/
# board/
# build/
# external/
# frameworks/
# logs/
# packages/
# prebuilts/
# quickapp/
# vendor/
```

## 🔧 常见问题

### Q1: WSL2 安装失败
```bash
# 确保启用虚拟化
# 在 BIOS 中启用 Intel VT-x 或 AMD-V

# 启用必要的 Windows 功能
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

# 设置 WSL2 为默认版本
wsl --set-default-version 2
```

### Q2: apt-get 更新失败
```bash
# 更换源为国内镜像
sudo sed -i 's/archive.ubuntu.com/mirrors.tuna.tsinghua.edu.cn/g' /etc/apt/sources.list
sudo apt-get update
```

### Q3: Repo sync 失败
```bash
# 减少并行数
repo sync -c -j1

# 或重试
repo sync -c -j4

# 检查网络
ping github.com
```

### Q4: 权限问题
```bash
# 确保使用 harryminei 用户
whoami  # 应该输出 harryminei

# 不要使用 sudo 运行 repo
# 如果需要，修复文件权限
sudo chown -R harryminei:harryminei ~/contest2026_325_junweiyanjiuyuan
```
