## 🔧 常见验证失败及修复

### 问题 1: 工具未找到
```bash
# 症状
$ cmake --version
bash: cmake: command not found

# 修复
sudo apt-get install -y cmake

# 或检查 PATH
echo $PATH
source ~/.bashrc
```

### 问题 2: Repo 状态异常
```bash
# 症状
$ repo status
error: repo is not installed

# 修复
cd ~/contest2026_325_junweiyanjiuyuan
repo init -u https://github.com/open-vela/contest2026_325_junweiyanjiuyuan \
  -b dev-ai-contest-2026 \
  -m contest2026_325_junweiyanjiuyuan.xml
repo sync -c -j4
```

### 问题 3: 编译失败
```bash
# 症状
./build.sh: command not found

# 修复
cd ~/contest2026_325_junweiyanjiuyuan/..
chmod +x build.sh
./build.sh <board-config-path> -j8
```

### 问题 4: 串口无法连接
```bash
# 症状
minicom: cannot open /dev/ttyUSB0: Permission denied

# 修复
sudo usermod -a -G dialout $USER
# 重新登录
# 或
sudo chmod 666 /dev/ttyUSB0
```
