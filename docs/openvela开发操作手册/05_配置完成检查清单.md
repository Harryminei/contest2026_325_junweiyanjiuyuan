# 05 配置完成检查清单

**用途**: 配置完成前的最终检查
**使用时机**: 所有配置步骤完成后
**预计时间**: 5-10 分钟

---

## 🎯 目标

在开始开发前，快速检查所有配置是否完整和正确，确保万无一失。

---

## ⚡ 快速检查（2分钟）

### 一键检查命令

```bash
# 复制并执行以下命令，快速验证配置
wsl -d Ubuntu-24.04 -- bash -c '
echo "=== openvela 开发环境快速检查 ==="
echo ""

# 1. 系统环境
echo "1. 系统环境："
whoami && uname -r | grep -q "WSL2" && echo "  ✅ WSL2 环境正常" || echo "  ❌ WSL2 环境异常"
echo ""

# 2. 核心工具
echo "2. 核心工具："
tools=("gcc" "git" "python3" "make" "repo")
all_ok=true
for tool in "${tools[@]}"; do
    if command -v "$tool" &> /dev/null; then
        echo "  ✅ $tool"
    else
        echo "  ❌ $tool"
        all_ok=false
    fi
done
echo ""

# 3. 工程目录
echo "3. 工程目录："
if [ -d ~/contest2026_325_junweiyanjiuyuan ]; then
    cd ~/contest2026_325_junweiyanjiuyuan
    missing=$(repo status 2>/dev/null | grep -c "missing")
    if [ "$missing" -eq 0 ]; then
        echo "  ✅ 工程代码完整"
    else
        echo "  ⚠️  有 $missing 个项目待同步"
    fi
else
    echo "  ❌ 工程目录不存在"
fi
echo ""

# 总结
if [ "$all_ok" = true ]; then
    echo "✅ 配置检查通过！可以开始开发。"
else
    echo "❌ 配置检查未通过，请修复上述问题。"
fi
'
```

**预期输出**：
```
=== openvela 开发环境快速检查 ===

1. 系统环境：
harryminei
  ✅ WSL2 环境正常

2. 核心工具：
  ✅ gcc
  ✅ git
  ✅ python3
  ✅ make
  ✅ repo

3. 工程目录：
  ✅ 工程代码完整

✅ 配置检查通过！可以开始开发。
```

## 📋 详细检查清单

### 第一部分：系统环境 ✅

#### 1.1 WSL2 检查
```bash
wsl -l -v
```

**检查项**：
- [ ] Ubuntu-24.04 出现在列表中
- [ ] STATE 为 Running
- [ ] VERSION 为 2

**如果未通过**：
```bash
# 启动 WSL2
wsl -d Ubuntu-24.04

# 或设置默认版本
wsl --set-default-version 2
```

#### 1.2 用户检查
```bash
wsl -d Ubuntu-24.04 -- whoami
```

**检查项**：
- [ ] 输出为 `harryminei`

**如果未通过**：
```bash
# 确保以正确用户进入
wsl -d Ubuntu-24.04 -u harryminei
```

#### 1.3 磁盘空间
```bash
wsl -d Ubuntu-24.04 -- df -h / | tail -1
```

**检查项**：
- [ ] 可用空间 > 50GB

**如果未通过**：
```bash
# 清理不需要的文件
sudo apt-get clean
rm -rf ~/.cache/pip
```

### 第二部分：开发工具 ✅

#### 2.1 GCC 编译器
```bash
wsl -d Ubuntu-24.04 -- bash -c "
  gcc --version | head -1
  arm-none-eabi-gcc --version | head -1
"
```

**检查项**：
- [ ] GCC (x86) 版本 13.x
- [ ] ARM GCC 版本 13.2.1

**如果未通过**：
```bash
# 安装 GCC
sudo apt-get update
sudo apt-get install -y gcc g++ build-essential

# 安装 ARM GCC
wget https://developer.arm.com/-/media/Files/downloads/gnu/13.2.rel1/binrel/arm-gnu-toolchain-13.2.rel1-x86_64-arm-none-eabi.tar.xz
tar -xf arm-gnu-toolchain-13.2.rel1-x86_64-arm-none-eabi.tar.xz
sudo mv arm-gnu-toolchain-13.2.rel1-x86_64-arm-none-eabi /opt/
echo 'export PATH="/opt/arm-gnu-toolchain-13.2.rel1-x86_64-arm-none-eabi/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

#### 2.2 Git 版本控制
```bash
wsl -d Ubuntu-24.04 -- git --version
```

**检查项**：
- [ ] Git 版本 2.43.0+

**如果未通过**：
```bash
sudo apt-get install -y git
git config --global user.name "Your Name"
git config --global user.email "your@email.com"
```

#### 2.3 Python
```bash
wsl -d Ubuntu-24.04 -- python3 --version
```

**检查项**：
- [ ] Python 版本 3.12+

**如果未通过**：
```bash
sudo apt-get install -y python3 python3-pip
```

#### 2.4 Make 构建工具
```bash
wsl -d Ubuntu-24.04 -- make --version | head -1
```

**检查项**：
- [ ] Make 版本 4.3+

**如果未通过**：
```bash
sudo apt-get install -y make
```

#### 2.5 CMake（可选）
```bash
wsl -d Ubuntu-24.04 -- cmake --version | head -1
```

**检查项**：
- [ ] CMake 已安装

**如果未通过**：
```bash
sudo apt-get install -y cmake
```

#### 2.6 Minicom（可选）
```bash
wsl -d Ubuntu-24.04 -- minicom --version | head -1
```

**检查项**：
- [ ] Minicom 已安装

**如果未通过**：
```bash
sudo apt-get install -y minicom
```

#### 2.7 Repo 工具
```bash
wsl -d Ubuntu-24.04 -- bash -c "
  export PATH='\$HOME/.bin:\$PATH'
  repo --version | grep 'launcher version'
"
```

**检查项**：
- [ ] Repo 工具已安装
- [ ] 版本 2.65+

**如果未通过**：
```bash
mkdir -p ~/.bin
curl https://storage.googleapis.com/git-repo-downloads/repo > ~/.bin/repo
chmod a+x ~/.bin/repo
```

### 第三部分：环境配置 ✅

#### 3.1 PATH 配置
```bash
wsl -d Ubuntu-24.04 -- bash -c "
  echo \$PATH | grep -q '.bin' && echo '✅ PATH 包含 .bin' || echo '❌ PATH 缺少 .bin'
"
```

**检查项**：
- [ ] PATH 包含 `~/.bin`

**如果未通过**：
```bash
echo 'export PATH="$HOME/.bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

#### 3.2 语言设置
```bash
wsl -d Ubuntu-24.04 -- bash -c "
  echo 'LANG:' \$LANG
  echo 'LC_ALL:' \$LC_ALL
"
```

**检查项**：
- [ ] LANG 为 `en_US.UTF-8`
- [ ] LC_ALL 为 `en_US.UTF-8`

**如果未通过**：
```bash
echo 'export LANG=en_US.UTF-8' >> ~/.bashrc
echo 'export LC_ALL=en_US.UTF-8' >> ~/.bashrc
source ~/.bashrc
```

#### 3.3 Shell 配置文件
```bash
wsl -d Ubuntu-24.04 -- grep -c "export" ~/.bashrc
```

**检查项**：
- [ ] ~/.bashrc 包含 export 语句

**如果未通过**：
```bash
# 检查是否有语法错误
bash -n ~/.bashrc && echo "✅ 语法正确" || echo "❌ 语法错误"
```
