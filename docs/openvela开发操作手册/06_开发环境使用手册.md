### 创建快应用

```bash
# 进入快应用目录
cd ~/contest2026_325_junweiyanjiuyuan/quickapp

# 创建项目
mkdir my_quickapp
cd my_quickapp

# 创建基本文件
cat > manifest.json << 'EOF'
{
  "package": "com.example.myquickapp",
  "name": "My QuickApp",
  "versionName": "1.0.0",
  "versionCode": 1,
  "minPlatformVersion": 1000,
  "icon": "/common/logo.png",
  "features": [],
  "permissions": [
    { "origin": "*" }
  ],
  "config": {
    "logLevel": "debug",
    "designWidth": 750
  },
  "router": {
    "entry": "pages/index",
    "pages": {
      "pages/index": {
        "component": "index"
      }
    }
  },
  "display": {
    "pages": {
      "pages/index": {
        "titleBar": true
      }
    }
  }
}
EOF

mkdir -p pages/index
cat > pages/index/index.js << 'EOF'
export default {
  data: {
    message: 'Hello openvela QuickApp!'
  },
  onInit() {
    console.log('QuickApp initialized')
  }
}
EOF

cat > pages/index/index.html << 'EOF'
<div>
  <text>{{ message }}</text>
</div>
EOF

cat > pages/index/index.css << 'EOF'
div {
  flex-direction: column;
  align-items: center;
  justify-content: center;
  height: 100%;
}

text {
  font-size: 40px;
  color: #000000;
}
EOF
```

### 快应用开发要点

1. **manifest.json** - 应用配置文件，定义包名、版本、路由等
2. **页面结构** - 每个页面包含 `.js`、`.html`、`.css` 三个文件
3. **数据绑定** - 使用 `{{ }}` 语法绑定数据
4. **生命周期** - `onInit`、`onReady`、`onShow`、`onHide` 等
5. **组件** - 使用内置组件如 `<div>`、`<text>`、`<image>` 等

### 创建嵌入式应用

```bash
# 进入应用目录
cd ~/contest2026_325_junweiyanjiuyuan/app

# 创建项目
mkdir my_app
cd my_app

# 创建主程序
cat > main.c << 'EOF'
#include <nuttx/config.h>
#include <stdio.h>
#include <unistd.h>

int main(int argc, char *argv[])
{
  printf("Hello openvela AI Hardware!\n");

  /* 主循环 */
  while (1)
    {
      printf("Running...\n");
      sleep(1);
    }

  return 0;
}
EOF

# 创建 Makefile
cat > Makefile << 'EOF'
include $(APPDIR)/Make.defs

# 应用名称
PROGNAME = my_app
PRIORITY = 100
STACKSIZE = 4096

# 源文件
CSRCS = main.c

include $(APPDIR)/Application.mk
EOF

# 创建 Kconfig
cat > Kconfig << 'EOF'
config MY_APP
	bool "My Application"
	default n
	---help---
		Enable my custom application for openvela contest.

if MY_APP

config MY_APP_PRIORITY
	int "My App priority"
	default 100
	---help---
		Priority of my application.

config MY_APP_STACKSIZE
	int "My App stack size"
	default 4096
	---help---
		Stack size of my application.

endif # MY_APP
EOF

# 创建 README
cat > README.md << 'EOF'
# My openvela AI Hardware Application

## 简介
这是我的 openvela AI 硬件赛道参赛作品。

## 功能
- 功能 1
- 功能 2
- 功能 3

## 编译
\`\`\`bash
cd ~/contest2026_325_junweiyanjiuyuan/..
./build.sh <board-config-path> -j8
\`\`\`

## 运行
烧录到设备后运行：
\`\`\`bash
nsh> my_app
\`\`\`
EOF
```

```bash
# 进入板级目录
cd ~/contest2026_325_junweiyanjiuyuan/board

# 创建项目
mkdir my_board
cd my_board

# 创建目录结构
mkdir -p src configs/nsh scripts

cat > src/board_init.c << 'EOF'
#include <nuttx/config.h>
#include <nuttx/board.h>
#include <stdio.h>

/* 板级初始化 */
int board_app_initialize(uintptr_t arg)
{
  printf("Board initialized!\n");

  /* 初始化硬件 */
  /* GPIO、UART、SPI、I2C 等 */

  return OK;
}

/* 板级晚期初始化 */
int board_late_initialize(void)
{
  printf("Board late initialization\n");
  return OK;
}
EOF

# 创建头文件
cat > src/board.h << 'EOF'
#ifndef __BOARD_H
#define __BOARD_H

/* 板级定义 */
#define BOARD_NAME "My Board"
#define BOARD_VERSION "1.0"

/* GPIO 定义 */
/* #define LED_PIN ... */
/* #define BUTTON_PIN ... */

/* 外设定义 */
/* #define UART_PORT ... */
/* #define SPI_PORT ... */

#endif /* __BOARD_H */
EOF

# 创建 Makefile
cat > src/Makefile << 'EOF'
include $(APPDIR)/Make.defs

# 板级源文件
CSRCS = board_init.c

include $(APPDIR)/Application.mk
EOF

# 创建默认配置
cat > configs/nsh/defconfig << 'EOF'
# My Board Configuration

# Architecture

CONFIG_ARCH_CHIP="my_chip"
CONFIG_ARCH_BOARD="my_board"

# System
CONFIG_BOARD_LOOPSPERMSEC=16000

# Console
CONFIG_UART1_SERIAL_CONSOLE=y
CONFIG_UART1_BAUD=115200
CONFIG_UART1_BITS=8
CONFIG_UART1_PARITY=0

# File System
CONFIG_FS_ROMFS=y

# Networking
CONFIG_NET=y
CONFIG_NET_TCP=y
CONFIG_NET_UDP=y

# Application
CONFIG_MY_APP=y
EOF

# 创建 Kconfig
cat > Kconfig << 'EOF'
if ARCH_BOARD_MY_BOARD

config BOARD_NAME
	string "Board Name"
	default "My Board"

config BOARD_VERSION
	string "Board Version"
	default "1.0"

# 更多板级配置选项...

endif # ARCH_BOARD_MY_BOARD
EOF

# 创建链接脚本
cat > scripts/ld.script << 'EOF'
/* 链接脚本 - 根据实际芯片调整 */

MEMORY
{
  FLASH (rx) : ORIGIN = 0x08000000, LENGTH = 512K
  RAM (rwx) : ORIGIN = 0x20000000, LENGTH = 128K
}

SECTIONS
{
  .text :
  {
    _stext = .;
    *(.vectors)
    *(.text .text.*)
    *(.rodata .rodata.*)
    _etext = .;
  } > FLASH

  .data :
  {
    _sdata = .;
    *(.data .data.*)
    _edata = .;
  } > RAM AT > FLASH

  .bss :
  {
    _sbss = .;
    *(.bss .bss.*)
    *(COMMON)
    _ebss = .;
  } > RAM
}
EOF
```

## Git工作流

### 基本工作流

```bash
# 1. 查看状态
git status

# 2. 添加文件
git add <file1> <file2>
# 或添加所有修改
git add .

# 3. 提交
git commit -m "描述你的修改"

# 4. 查看提交历史
git log --oneline -10

# 5. 推送到远程
git push origin main
```

### 分支管理

```bash
# 查看分支
git branch -a

# 创建并切换分支
git checkout -b feature/my-feature

# 切换分支
git checkout main

# 合并分支
git merge feature/my-feature

# 删除分支
git branch -d feature/my-feature
```

### 代码同步

```bash
# 拉取最新代码
git pull origin main

# 如果有冲突
git merge origin/main
# 解决冲突后
git add .
git commit -m "Merge origin/main"
```

### 提交规范

**提交信息格式**：
```
<类型>(<范围>): <主题>

<正文>

<脚注>
```

**类型**：
- `feat`: 新功能
- `fix`: 修复 bug
- `docs`: 文档更新
- `style`: 代码格式调整
- `refactor`: 重构
- `test`: 测试相关
- `chore`: 构建/工具链更新

**示例**：
```bash
git commit -m "feat(quickapp): 添加首页组件

- 实现首页布局
- 添加数据绑定
- 优化样式

Closes #123"
```

### 创建 Pull Request

```bash
# 1. Fork 仓库（在 GitHub 上操作）

# 2. 添加远程仓库
git remote add myfork https://github.com/yourusername/contest2026_325_junweiyanjiuyuan.git

# 3. 推送到你的 Fork
git push myfork main

# 4. 在 GitHub 上创建 Pull Request

# 5. 等待审核和合并
```

## 常见问题

### 环境配置问题

#### Q1: WSL2 安装失败

**症状**：
```
Error: 0x1bc
```

**解决方案**：
```bash
# 1. 启用必要的 Windows 功能
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

# 2. 下载并安装 WSL2 Linux 内核更新包
# https://aka.ms/wsl2kernel

# 3. 设置 WSL2 为默认版本
wsl --set-default-version 2

# 4. 重启计算机
```

#### Q2: 网络连接问题

**症状**：
```
fatal: unable to access 'https://github.com/...': Could not resolve host
```

**解决方案**：
```bash
# 1. 检查网络连接
ping github.com

# 2. 配置 Git 代理（如果有）
git config --global http.proxy http://proxy:port
git config --global https.proxy http://proxy:port

# 3. 使用国内镜像
export REPO_URL='https://gerrit-googlesource.lug.ustc.edu.cn/git-repo'

# 4. 减少并行数
repo sync -c -j1
```

#### Q3: Repo sync 失败

**症状**：
```
error: Cannot fetch ...
```

**解决方案**：
```bash
# 1. 减少并行数
repo sync -c -j1

# 2. 重试
repo sync -c -j4

# 3. 清理重试
repo sync -c -j4 --force-sync

# 4. 检查磁盘空间
df -h
```

#### Q4: 权限问题

**症状**：
```
Permission denied
```

**解决方案**：
```bash
# 1. 确保使用 harryminei 用户
whoami

# 2. 修复文件权限
sudo chown -R harryminei:harryminei ~/contest2026_325_junweiyanjiuyuan

# 3. 不要使用 sudo 运行 repo
# 如果需要，先修复权限
```

### 编译问题

#### Q5: 编译错误 - 缺少依赖

**症状**：
```
fatal error: xxx.h: No such file or directory
```

**解决方案**：
```bash
# 1. 更新包列表
sudo apt-get update

# 2. 安装缺失的包
sudo apt-get install -y <missing-package>

# 3. 清除缓存重新编译
./build.sh <board-config-path> distclean
./build.sh <board-config-path> -j8
```

#### Q6: 编译错误 - 配置问题

**症状**：
```
error: CONFIG_XXX is not set
```

**解决方案**：
```bash
# 1. 进入配置菜单
./build.sh <board-config-path> menuconfig

# 2. 启用缺失的配置
# 根据错误信息找到对应配置并启用

# 3. 重新编译
./build.sh <board-config-path> -j8
```

#### Q7: 编译速度慢

**解决方案**：
```bash
# 1. 增加并行任务数（根据 CPU 核心数）
./build.sh <board-config-path> -j16

# 2. 使用 ccache（如果可用）
export CCACHE_DIR=~/.ccache
./build.sh <board-config-path> -j8

# 3. 只编译修改的部分
./build.sh <board-config-path> -j8 apps/my_app
```

### 调试问题

#### Q8: 串口无法连接

**症状**：
```
minicom: cannot open /dev/ttyUSB0: Permission denied
```

**解决方案**：
```bash
# 1. 检查串口设备
ls /dev/ttyUSB*

# 2. 添加用户到 dialout 组
sudo usermod -a -G dialout $USER

# 3. 重新登录
# 或者临时修改权限
sudo chmod 666 /dev/ttyUSB0

# 4. 重新连接
minicom -D /dev/ttyUSB0 -b 115200
```

#### Q9: GDB 连接失败

**症状**：
```
Remote communication error.  Target disconnected.
```

**解决方案**：
```bash
# 1. 检查调试器连接
# 确保 J-Link/ST-Link 已连接

# 2. 启动 GDB 服务器
# J-Link:
JLinkGDBServer -device <device> -if SWD -speed 4000

# 3. 在另一个终端连接 GDB
arm-none-eabi-gdb nuttx
(gdb) target remote :2331
```

### Git 问题

#### Q10: Git push 被拒绝

**症状**：
```
! [rejected]        main -> main (non-fast-forward)
```

**解决方案**：
```bash
# 1. 拉取最新代码
git pull origin main

# 2. 解决冲突（如果有）
git merge origin/main
# 编辑冲突文件
git add .
git commit -m "Merge origin/main"

# 3. 再次推送
git push origin main
```

#### Q11: Git 合并冲突

**解决方案**：
```bash
# 1. 查看冲突文件
git status

# 2. 编辑冲突文件
vim <conflicted-file>

# 冲突标记：
<<<<<<< HEAD
你的代码
=======
其他人的代码
>>>>>>> origin/main

# 3. 选择保留的代码，删除冲突标记

# 4. 标记为已解决
git add <conflicted-file>

# 5. 完成合并
git commit -m "Merge origin/main"
```
