### 步骤 4：开始开发

选择赛道后，按照以下流程开发：

#### 4.1 创建项目
```bash
# 根据赛道进入目录
cd ~/contest2026_325_junweiyanjiuyuan/<赛道目录>

# 创建项目
mkdir <项目名>
cd <项目名>
```

#### 4.2 编写代码
```bash
# 使用编辑器
vim main.c
# 或
code .  # VSCode

# 参考赛道教程和示例代码
```

#### 4.3 编译测试
```bash
# 进入 openvela 工作区根目录
cd ~/contest2026_325_junweiyanjiuyuan/..

# 编译（替换 <board-config-path> 为实际配置）
./build.sh <board-config-path> -j8

# 查看编译日志
tail -f build.log
```

#### 4.4 调试优化
```bash
# 串口调试（如有硬件）
minicom -D /dev/ttyUSB0 -b 115200

# GDB 调试
arm-none-eabi-gdb nuttx
```

#### 4.5 提交代码
```bash
# 查看修改
git status

# 添加文件
git add .

# 提交
git commit -m "描述你的修改"

# 推送
git push origin main
```

#### 4.6 记录日志
```bash
# 使用 AI Coding 工具时，保存对话记录
cp <ai-log> ~/contest2026_325_junweiyanjiuyuan/logs/

# 命名规范：日期_工具_任务.md
# 例如：2026-08-20_claude-code_开发hello-world.md
```

## 🔧 开发技巧

### 1. 高效使用命令行

```bash
# 快速导航
cd ~/contest2026_325_junweiyanjiuyuan

# 历史命令
history | grep build

# 别名
alias ll='ls -la'
alias build='./build.sh <board-config-path> -j8'
```

### 2. 编译优化

```bash
# 只编译修改的部分
./build.sh <board-config-path> -j8 apps/my_app

# 使用 ccache
export CCACHE_DIR=~/.ccache

# 并行编译
./build.sh <board-config-path> -j16
```

### 3. 调试技巧

```bash
# 串口日志
minicom -C debug.log -D /dev/ttyUSB0 -b 115200

# GDB 断点
(gdb) break my_function
(gdb) condition 1 i==10  # 条件断点

# 查看内存
(gdb) x/10x 0x20000000
```
