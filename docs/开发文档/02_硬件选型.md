## 🎯 选型原则

### 1. 场景适配原则
- **手环端**：穿戴设备，优先考虑功耗、体积、佩戴舒适度
- **Hub端**：桌面设备，优先考虑性能、交互体验、扩展性

### 2. 生态兼容原则
- 优先选择 openvela 支持的硬件平台
- 考虑开发资源和社区支持
- 评估长期维护和升级路径

### 3. 成本效益原则
- 平衡性能与成本
- 考虑量产可行性
- 评估供应链稳定性

### 4. 差异化竞争原则
- 选择有特色的硬件平台
- 突出技术亮点
- 避免同质化竞争

### 最终选择：黄山派SF32LB52

#### 选择理由

**1. 专为穿戴设计**
- SF32LB52 是黄山派专为智能穿戴设计的芯片
- 针对手环、手表等场景深度优化
- 低功耗设计，续航优势明显

**2. 集成度高**
- 内置六轴 IMU（加速度+陀螺仪）
- 集成 BLE 5.0 基带和射频
- 支持 LCD 驱动，减少外围器件
- 降低 BOM 成本和 PCB 面积

**3. openvela 完整支持**
- 官方适配 openvela 系统
- 提供完整的板级支持包（BSP）
- 社区活跃，文档完善
- 开发效率高

**4. 功耗表现优异**
- 动态功耗：15μA/MHz
- 深度休眠：1.5μA
- BLE 广播：10μA
- 满足 7 天+续航要求

**5. 开发资源丰富**
- 提供完整的 SDK
- 示例代码丰富
- 技术支持完善
- 社区交流活跃

#### 核心参数详解

**处理器**：
```
架构：ARM Cortex-M4F
主频：64MHz
FPU：支持单精度浮点
DSP：支持 DSP 指令集
```

**存储**：
```
Flash：512KB（可扩展至 1MB）
SRAM：128KB（可扩展至 256KB）
PSRAM：4MB（可选）
```

**无线通信**：
```
协议：BLE 5.0
速率：2Mbps
距离：100m+（空旷环境）
功耗：10μA（广播模式）
```

**传感器**：
```
六轴 IMU：
  - 加速度计：±2/4/8/16g
  - 陀螺仪：±125/250/500/1000/2000°/s
  - 采样率：最高 6.66kHz
  - 接口：I2C/SPI
```

**显示接口**：
```
接口：SPI/QSPI
分辨率：支持 240x240、320x320
色彩：RGB565、RGB888
刷新率：60fps
```

**电源管理**：
```
工作电压：1.8V - 3.6V
功耗模式：
  - Active：15μA/MHz
  - Sleep：3μA
  - Deep Sleep：1.5μA
  - Shutdown：0.5μA
充电：支持锂电充电管理
```

**外设接口**：
```
GPIO：32 个
UART：2 个
SPI：2 个
I2C：2 个
ADC：12-bit，8 通道
Timer：4 个
```

## 📐 PCB 设计要点

### 手环端 PCB 设计

**布局原则**：
- IMU 靠近佩戴位置，减少干扰
- 天线区域净空，保证 BLE 信号
- 电池接口靠近充电管理芯片
- 按键位置符合人体工学

**关键设计**：
```
1. 天线设计
   - BLE 天线：PIFA 或倒F天线
   - 净空区域：≥5mm
   - 匹配网络：π型匹配

2. 电源设计
   - 去耦电容：100nF + 10μF
   - 电源层：完整铺铜
   - 模拟/数字地分离

3. IMU 布局
   - 远离振动源
   - 固定牢靠
   - 走线短且对称

4. 充电管理
   - Type-C 接口
   - 充电 IC：线性充电
   - 保护电路：过充/过放/过流
```

**PCB 规格**：
```
层数：4层
尺寸：30mm x 30mm
厚度：1.0mm
材质：FR-4
铜厚：1oz
最小线宽/间距：4mil/4mil
```

### Hub端 PCB 设计

**布局原则**：
- WiFi 天线远离音频电路，减少干扰
- 音频电路独立分区，降低噪声
- 电源模块集中布局
- 散热设计合理

**关键设计**：
```
1. 音频设计
   - 麦克风：双麦克风阵列，间距 2-3cm
   - 回声消除：硬件 AEC 参考信号采集
   - 地平面：模拟地与数字地分离
   - 屏蔽：音频区域局部屏蔽

2. WiFi 设计
   - 天线：外置天线，IPEX 接口
   - 匹配：50Ω 匹配网络
   - 走线：微带线，控制阻抗
   - 净空：天线区域净空 ≥10mm

3. 电源设计
   - 输入：5V USB 供电
   - 转换：DC-DC + LDO
   - 去耦：多级去耦
   - 保护：过压/过流/ESD

4. 散热设计
   - 散热铜皮
   - 导热垫
   - 风扇接口（可选）
```

**PCB 规格**：
```
层数：6层
尺寸：80mm x 60mm
厚度：1.6mm
材质：FR-4
铜厚：1oz
最小线宽/间距：4mil/4mil
```
