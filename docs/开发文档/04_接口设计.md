## 🔌 硬件接口

### 1. 手环端硬件接口

#### 1.1 IMU 接口（I2C）

**接口参数**：
```
协议：I2C
速率：400kHz
地址：0x6A（加速度+陀螺仪）
中断：INT1 → GPIO_PA03
```

**寄存器定义**：
```c
/* LSM6DSO 寄存器 */
#define WHO_AM_I        0x0F
#define CTRL1_XL        0x10
#define CTRL2_G         0x11
#define CTRL3_C         0x12
#define OUTX_L_XL       0x28
#define OUTX_H_XL       0x29
#define OUTY_L_XL       0x2A
#define OUTY_H_XL       0x2B
#define OUTZ_L_XL       0x2C
#define OUTZ_H_XL       0x2D

/* 数据结构 */
typedef struct {
    int16_t acc_x;   /* X轴加速度 */
    int16_t acc_y;   /* Y轴加速度 */
    int16_t acc_z;   /* Z轴加速度 */
    int16_t gyro_x;  /* X轴角速度 */
    int16_t gyro_y;  /* Y轴角速度 */
    int16_t gyro_z;  /* Z轴角速度 */
} imu_raw_data_t;
```

**读取函数**：
```c
int imu_read_data(imu_raw_data_t *data) {
    uint8_t buf[12];
    int ret;

    /* 读取 6 轴数据 */
    ret = i2c_read(IMU_I2C_ADDR, OUTX_L_XL, buf, 12);
    if (ret < 0) return ret;

    /* 解析数据 */
    data->acc_x = (int16_t)(buf[1] << 8 | buf[0]);
    data->acc_y = (int16_t)(buf[3] << 8 | buf[2]);
    data->acc_z = (int16_t)(buf[5] << 8 | buf[4]);
    data->gyro_x = (int16_t)(buf[7] << 8 | buf[6]);
    data->gyro_y = (int16_t)(buf[9] << 8 | buf[8]);
    data->gyro_z = (int16_t)(buf[11] << 8 | buf[10]);

    return 0;
}
```

#### 1.2 LCD 接口（SPI）

**接口参数**：
```
协议：SPI
速率：最高 50MHz
分辨率：240x240
色彩：RGB565
驱动芯片：ST7789
```

**初始化序列**：
```c
void lcd_init(void) {
    /* 硬件复位 */
    gpio_set(LCD_RST_PIN, 0);
    usleep(10000);
    gpio_set(LCD_RST_PIN, 1);
    usleep(10000);

    /* 软件复位 */
    lcd_write_cmd(0x01);
    usleep(150000);

    /* 初始化序列 */
    lcd_write_cmd(0x11);  /* Sleep Out */
    usleep(120000);

    lcd_write_cmd(0x36);  /* Memory Data Access Control */
    lcd_write_data(0x00);

    lcd_write_cmd(0x3A);  /* Interface Pixel Format */
    lcd_write_data(0x55); /* 16bit/pixel */

    lcd_write_cmd(0x29);  /* Display On */
}
```

#### 1.3 按键接口（GPIO）

**接口参数**：
```
SOS 按键：GPIO_PA01（中断，上拉）
功能按键：GPIO_PA02（中断，上拉）
```

**中断配置**：
```c
void button_init(void) {
    /* SOS 按键配置 */
    gpio_config(SOS_BTN_PIN, GPIO_INPUT | GPIO_PULL_UP | GPIO_INT_FALLING);
    gpio_attach_interrupt(SOS_BTN_PIN, sos_button_isr, GPIO_INT_FALLING);

    /* 功能按键配置 */
    gpio_config(FUNC_BTN_PIN, GPIO_INPUT | GPIO_PULL_UP | GPIO_INT_FALLING);
    gpio_attach_interrupt(FUNC_BTN_PIN, func_button_isr, GPIO_INT_FALLING);
}

/* SOS 按键中断处理 */
void sos_button_isr(void *arg) {
    /* 启动定时器，检测长按 */
    start_timer(SOS_LONG_PRESS_TIME, sos_long_press_callback, NULL);
}
```

#### 1.4 振动马达接口（PWM）

**接口参数**：
```
接口：PWM
通道：PWM_CH0
频率：200Hz
占空比：可调（0-100%）
```

**振动模式**：
```c
/* 振动模式定义 */
typedef enum {
    VIBRATE_SHORT,      /* 短振动 */
    VIBRATE_LONG,       /* 长振动 */
    VIBRATE_PATTERN,    /* 自定义模式 */
    VIBRATE_SOS         /* SOS模式 */
} vibrate_mode_t;

/* 振动控制 */
void motor_vibrate(vibrate_mode_t mode) {
    switch (mode) {
        case VIBRATE_SHORT:
            pwm_set_duty(PWM_CH0, 50);
            usleep(100000);  /* 100ms */
            pwm_set_duty(PWM_CH0, 0);
            break;

        case VIBRATE_LONG:
            pwm_set_duty(PWM_CH0, 50);
            usleep(500000);  /* 500ms */
            pwm_set_duty(PWM_CH0, 0);
            break;

        case VIBRATE_SOS:
            /* SOS 模式：三短三长三短 */
            for (int i = 0; i < 3; i++) {
                pwm_set_duty(PWM_CH0, 50);
                usleep(100000);
                pwm_set_duty(PWM_CH0, 0);
                usleep(100000);
            }
            break;
    }
}
```

### 2. Hub端硬件接口

#### 2.1 麦克风接口（I2S）

**接口参数**：
```
协议：I2S
采样率：16kHz
位深：16bit
通道：双声道（立体声）
缓冲区：4KB x 4
```

**初始化配置**：
```c
void mic_init(void) {
    i2s_config_t config = {
        .mode = I2S_MODE_MASTER | I2S_MODE_RX,
        .sample_rate = 16000,
        .bits_per_sample = 16,
        .channel_format = I2S_CHANNEL_FMT_RIGHT_LEFT,
        .communication_format = I2S_COMM_FORMAT_STAND_I2S,
        .intr_alloc_flags = 0,
        .dma_buf_count = 4,
        .dma_buf_len = 1024,
        .use_apll = false
    };

    i2s_driver_install(I2S_NUM_0, &config, 0, NULL);
    i2s_set_pin(I2S_NUM_0, &mic_pin_config);
}
```

#### 2.2 扬声器接口（I2S + 功放）

**接口参数**：
```
协议：I2S
采样率：16kHz / 44.1kHz
位深：16bit
功放：NS4168（1W）
```

**播放控制**：
```c
void audio_play(const char *text) {
    /* 1. TTS 合成 */
    audio_buffer_t *buffer = cloud_tts(text);

    /* 2. 播放音频 */
    size_t bytes_written;
    i2s_write(I2S_NUM_0, buffer->data, buffer->size,
              &bytes_written, portMAX_DELAY);

    /* 3. 等待播放完成 */
    i2s_zero_dma_buffer(I2S_NUM_0);

    /* 4. 释放缓冲区 */
    free_audio_buffer(buffer);
}
```

## 📡 通信协议

### 1. BLE GATT 协议

#### 1.1 服务定义

**Service UUID**：
```
主服务：0x1820（自定义）
```

**Characteristic UUID**：
```
SOS 告警：0x2A01（Read, Notify）
活动状态：0x2A02（Read, Notify）
健康数据：0x2A03（Read, Notify）
同步命令：0x2A04（Write）
电池电量：0x2A19（Read, Notify）
```

#### 1.2 SOS 告警特征（0x2A01）

**数据格式**：
```c
typedef struct __attribute__((packed)) {
    uint8_t alert_type;      /* 告警类型 */
    uint32_t timestamp;      /* 时间戳（秒） */
    uint8_t battery_level;   /* 电池电量 */
} sos_alert_t;

/* alert_type 定义 */
#define ALERT_NONE          0x00
#define ALERT_SOS           0x01
#define ALERT_FALL          0x02
#define ALERT_ABNORMAL      0x03
```

**示例数据**：
```
告警类型：SOS (0x01)
时间戳：1692508800 (2026-08-20 08:00:00)
电量：85%
数据包：01 00 84 A4 64 55
```

#### 1.3 活动状态特征（0x2A02）

**数据格式**：
```c
typedef struct __attribute__((packed)) {
    uint8_t activity_type;   /* 活动类型 */
    uint16_t duration;       /* 持续时间（秒） */
    uint16_t steps;          /* 步数 */
    uint32_t timestamp;      /* 时间戳 */
} activity_status_t;

/* activity_type 定义 */
#define ACTIVITY_ACTIVE     0x00
#define ACTIVITY_SITTING    0x01
#define ACTIVITY_STILL      0x02
#define ACTIVITY_SLEEPING   0x03
```

#### 1.4 健康数据特征（0x2A03）

**数据格式**：
```c
typedef struct __attribute__((packed)) {
    uint16_t heart_rate;     /* 心率 (bpm) */
    uint8_t spo2;            /* 血氧 (%) */
    uint16_t systolic;       /* 收缩压 (mmHg) */
    uint16_t diastolic;      /* 舒张压 (mmHg) */
    uint16_t steps;          /* 步数 */
    uint32_t timestamp;      /* 时间戳 */
} health_data_t;
```

#### 1.5 同步命令特征（0x2A04）

**命令定义**：
```c
/* 命令类型 */
#define CMD_SYNC_TIME       0x01  /* 同步时间 */
#define CMD_SET_REMINDER    0x02  /* 设置提醒 */
#define CMD_SET_ALARM       0x03  /* 设置闹钟 */
#define CMD_OTA_START       0x04  /* 开始OTA */
#define CMD_RESET           0x05  /* 重置设备 */

/* 命令数据结构 */
typedef struct __attribute__((packed)) {
    uint8_t cmd_type;        /* 命令类型 */
    uint8_t cmd_data[16];    /* 命令数据 */
} sync_command_t;
```

### 3. HTTP REST API

#### 3.1 API 基础信息

**Base URL**: `https://api.silver-guardian.com/v1`

**认证方式**: Bearer Token（JWT）

**通用响应格式**：
```json
{
    "code": 200,
    "message": "success",
    "data": {}
}
```

**错误响应格式**：
```json
{
    "code": 400,
    "message": "Invalid parameter",
    "error": {
        "field": "user_id",
        "detail": "User ID is required"
    }
}
```

#### 3.2 健康数据接口

**查询健康数据**

```
GET /health/{user_id}
Authorization: Bearer <token>

Query Parameters:
  - type: 数据类型（可选）
  - start_time: 开始时间（可选）
  - end_time: 结束时间（可选）
  - limit: 返回数量（默认 100）
```

**响应示例**：
```json
{
    "code": 200,
    "data": {
        "user_id": "user_123",
        "records": [
            {
                "type": "blood_pressure",
                "value": {"systolic": 130, "diastolic": 80},
                "unit": "mmHg",
                "recorded_at": "2026-08-20T08:00:00Z",
                "is_normal": true
            }
        ],
        "total": 150
    }
}
```

**记录健康数据**

```
POST /health/{user_id}
Authorization: Bearer <token>

Request Body:
{
    "type": "blood_pressure",
    "value": {
        "systolic": 130,
        "diastolic": 80
    },
    "unit": "mmHg",
    "recorded_at": "2026-08-20T08:00:00Z",
    "source": "voice"
}
```

**响应示例**：
```json
{
    "code": 200,
    "data": {
        "record_id": "health_20260820_001",
        "is_normal": true,
        "alert_level": "none"
    }
}
```

uint32_t timestamp = 1692508800;  // 秒

## 🔐 安全规范

### 1. 认证机制

**JWT Token**：
```
Header:
{
    "alg": "HS256",
    "typ": "JWT"
}

Payload:
{
    "user_id": "user_123",
    "device_id": "band_001",
    "exp": 1692595200,
    "iat": 1692508800
}
```

**Token 刷新**：
```
POST /auth/refresh
Authorization: Bearer <old_token>

Response:
{
    "access_token": "new_token",
    "refresh_token": "new_refresh_token",
    "expires_in": 3600
}
```

### 2. 数据加密

**传输层**：
- HTTPS/TLS 1.3
- WSS (WebSocket Secure)
- BLE AES-128
