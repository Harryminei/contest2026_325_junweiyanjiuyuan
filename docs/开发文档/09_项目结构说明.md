## 🔧 工具脚本

### 环境监控脚本
**位置**: `openvela开发操作手册/09_环境监控脚本.sh`
**用途**: 自动化检查开发环境状态

**使用方法**：
```bash
# 进入 WSL2
wsl -d Ubuntu-24.04

# 复制脚本到 WSL2（可选）
cp /mnt/d/Desktop/首届openvela比赛/openvela开发操作手册/09_环境监控脚本.sh ~/

# 添加执行权限
chmod +x 09_环境监控脚本.sh

# 运行脚本
./09_环境监控脚本.sh
```

**检查内容**：
- ✅ WSL2 环境状态
- ✅ 开发工具安装情况
- ✅ 环境变量配置
- ✅ 工程代码同步状态
- ✅ 总体完成度百分比
