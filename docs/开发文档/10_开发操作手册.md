## 🔧 手环端开发指南

### 硬件准备

- **开发板**: 黄山派 SF32LB52
- **调试器**: J-Link 或 串口调试器
- **连接线**: USB 线、杜邦线

### 开发环境

```bash
# 1. 进入 WSL2
wsl -d Ubuntu-24.04

# 2. 进入工作区
cd ~/contest2026_325_junweiyanjiuyuan

# 3. 加载环境
source ~/.bashrc
```

### 代码结构

```
app/silver_guardian_band/
├── src/
│   ├── main.c      # 主程序入口
│   ├── sos.c       # SOS 呼救功能
│   ├── imu.c       # IMU 久坐检测
│   ├── ble.c       # BLE 通信
│   └── ui.c        # LVGL 界面
├── include/
│   ├── sos.h
│   ├── imu.h
│   ├── ble.h
│   └── ui.h
├── Kconfig         # 配置选项
├── Makefile        # 构建脚本
└── README.md
```

### 编译步骤

```bash
# 1. 进入 openvela 工作区根目录
cd ~/contest2026_325_junweiyanjiuyuan/..

# 2. 配置（可选）
./build.sh vendor/sifli/boards/sf32lb52/lckfb_huangshan_pi/configs/nsh menuconfig

# 3. 编译
./build.sh vendor/sifli/boards/sf32lb52/lckfb_huangshan_pi/configs/nsh -j8

# 4. 清除编译产物
./build.sh vendor/sifli/boards/sf32lb52/lckfb_huangshan_pi/configs/nsh distclean
```

### 调试技巧

#### 查看日志
```bash
# 连接串口，查看 syslog 输出
minicom -D /dev/ttyUSB0 -b 115200

# 日志会显示：
# [sos] SOS triggered!
# [imu] Sitting reminder: 60 minutes
# [ble] Sending SOS alert
```

#### 使用 GDB 调试
```bash
# 启动 GDB 服务器（需要 J-Link）
JLinkGDBServer -device SF32LB52 -if SWD -speed 4000

# 另一个终端启动 GDB
arm-none-eabi-gdb nuttx

# 连接目标
(gdb) target remote :2331

# 设置断点
(gdb) break sos_check

# 运行
(gdb) continue
```

## 🔗 双端联调

### 联调准备

1. **手环端**: 烧录固件，确保 BLE 已初始化
2. **Hub端**: 烧录固件，确保 WiFi 已连接
3. **距离**: 手环和 Hub 距离 < 10 米

### 联调步骤

#### 步骤 1: BLE 连接
```bash
# 手环端会自动开始 BLE 广播
# Hub 端会自动搜索并连接

# 在 Hub 端查看连接状态
nsh> ble status
```

#### 步骤 2: SOS 联调
```bash
# 1. 长按手环 SOS 按键 3 秒
# 2. 观察手环端响应（震动、屏幕显示）
# 3. 观察 Hub 端响应（语音、LCD、云端）
# 4. 观察家属端接收告警
```

#### 步骤 3: 久坐检测联调
```bash
# 1. 让手环静止 60 分钟
# 2. 观察手环端提醒
# 3. 观察 Hub 端语音播报
# 4. 检查云端记录
```

#### 步骤 4: 用药提醒联调
```bash
# 1. 配置用药计划
# 2. 等待提醒时间
# 3. 观察 Hub 端显示和语音
# 4. 观察手环端同步
# 5. 确认服药
```

### 联调问题排查

#### 问题 1: BLE 连接失败

## 🧪 自动化测试

### 单元测试框架

```bash
# 创建测试目录
mkdir -p tests/unit

# 编写测试用例
cat > tests/unit/test_sos.c << 'EOF'
#include <stdio.h>
#include <assert.h>
#include "../../app/silver_guardian_band/include/sos.h"

void test_sos_init() {
    int ret = sos_init();
    assert(ret == 0);
    sos_deinit();
}

void test_sos_trigger() {
    sos_init();
    int ret = sos_trigger_manual();
    assert(ret == 0);
    assert(sos_is_triggered() == true);
    sos_deinit();
}

int main() {
    test_sos_init();
    test_sos_trigger();
    printf("All tests passed!\n");
    return 0;
}
EOF
```

## 📝 开发最佳实践

### 代码规范

1. **命名规范**
   - 函数：`模块_功能`（如 `sos_init()`）
   - 变量：`g_` 前缀表示全局变量
   - 常量：全大写，下划线分隔

2. **注释规范**
   - 文件头：版权、描述
   - 函数头：功能、参数、返回值
   - 关键代码：解释逻辑

3. **错误处理**
   - 检查返回值
   - 使用 syslog 记录错误
   - 资源清理

### 版本控制

```bash
# 提交规范
git commit -m "feat(module): add new feature"
git commit -m "fix(module): fix bug description"
git commit -m "docs(module): update documentation"
```

### 代码审查

- 使用 GitHub Pull Request
- 至少一人审查
- 检查代码质量
- 运行测试用例
