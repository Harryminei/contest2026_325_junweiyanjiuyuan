## ③ 替换出厂 fes1/boot0（不改必卡 0%）

> PhoenixSuit 只认**出厂固件**配套的引导文件，用我们自编的会卡 0%。

1. 用出厂固件 `D:\Desktop\首届openvela比赛\tools\gemini_s1_mini.img` 提取（或用现成文件）：
   - `fes1.fex`（@ 0xba400，21504 字节）
   - `boot0_nand.fex`（@ 0x12c00，45056 字节）
2. 把这两个替换到打包目录的 `image/` 里
3. 手动生成镜像：
   ```bash
   dragon image.cfg sys_partition_for_dragon.fex   # 第二参数必须带，否则只有2MB
   ```

## ④ PhoenixSuit 烧录

1. 把 **`.img` 放到英文路径**（如 `C:\Users\Public\firmware\`），不要放中文/桌面路径
2. 运行 `D:\Desktop\首届openvela比赛\tools\PhoenixSuit\PhoenixSuit.exe`
3. 选「一键刷机」→ 浏览选择 `.img` → 模式「**全盘擦除升级**」
4. 点「刷机」，按提示让板子进 FEL（断电再上电，或 adb 触发重启）
5. 等进度条到 100%，板子自动重启

> 若卡 0%：回步骤③检查 fes1/boot0；若提示"固件文件打开失败"：检查 bootloader 分区 size（应=16384）；若工具本身异常：**重新解压 PhoenixSuit**。
